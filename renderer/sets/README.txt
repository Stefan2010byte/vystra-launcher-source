Vystra Sets - Banner-Bilder
===========================
Lege hier die Set-Banner als PNG ab (16:9, ~1024x576 oder groesser).
Dateinamen EXAKT so (kleingeschrieben):

  xbox.png          -> Xbox All-in-One Set
  playstation.png   -> PlayStation Set
  nintendo.png      -> Nintendo Set
  handheld.png      -> Handheld Set
  vr.png            -> VR Set
  retro.png         -> Retro Set
  streamer.png      -> Streamer Set
  starter.png       -> Starter Gaming Bundle
  cozy.png          -> Cozy & Chill Set
  cyberpunk.png     -> Cyberpunk Set
  esports.png       -> eSports Pro Set
  creator.png       -> Creator Set
  laptop.png        -> Laptop Set

Geplant (Bilder noch nicht erzeugt, Slot noch nicht in VYSTRA_SETS):
  racing.png        -> Racing / Lenkrad Set   (Produkte via BigBuy)
  flight.png        -> Flight / Flugzeug Set  (Produkte via BigBuy)
  boat.png          -> Boat / Boot Set        (Produkte via BigBuy)

Fehlt ein Bild, zeigt die Karte den Set-Namen auf Akzent-Verlauf (kein Fehler).
Fuer die Web-Version (vystra.games/webapp) dieselben Dateien auch nach
F:\Vystra_Website\launcher\sets\ kopieren.
Die Set-Liste steht in renderer/app.js (const VYSTRA_SETS) - spaeter per API ersetzbar.
